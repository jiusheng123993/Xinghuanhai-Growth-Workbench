## 四、赛道前景：真实，且真金白银在进场

**需求侧（🟡 中）**：2025 年城镇犬猫 **1.26 亿只**；**每年约 300 万只宠物离世**（北京约 15 万只）；**64.6%** 的宠主会为宠物办葬礼。

**行业级判断（🟢 高，两处独立同向）**：
> 「基础服务流程趋近同质化，针对宠物本身的基础服务已无上升空间……
> **具备高情绪价值的告别仪式和纪念品正在成为行业核心盈利点**。」——《中国质量报》2026-09-11

**星河宠记所在的位置**：**数字纪念**。行业已把它点名为新兴方向（「VR 告别、数字纪念馆等新兴形式」），
且**不碰遗体/火化 → 不在殡葬监管的直接射程内**（北京目前没有一家真正合规的宠物殡葬店）。

**资本在进（我联网独立核实为真，非项目文档自述）**：

| 公司 | 时点 | 金额 |
|---|---|---|
| 梦塔科技（AI 数字生命） | 2026-07 | 超千万元种子+轮 |
| 星联未来 SATELLAI | 2026-01 | 数千万元 A 轮（商汤国香资本领投） |
| MOVA AI 宠物 / 灵尾纪元 | 2026-02 | 数千万元 A 轮 |

**价格锚点（真实成交，非估算）**：闲鱼「AI 复活/纪念」**5 元/次** ← 星河 25.9-99 元 → 博主手工定制 **100-300 元/条**；
含「数字纪念馆」的殡葬套餐卖到 **5,000 元以上**。**星河卡在这条带子的中段：上有空间、下有护城河。**

**国内直接竞品**：项目文档 2026-09 两次检索**均未发现同构产品化竞品**。
⚠️ 但「没检索到」≠「不存在」，这是判定「蓝海」的**已知弱点**。

## 五、⚠️ 单位经济：这是最扎人的地方（已按 04 更正）

| 口径 | 数字 | 说明 |
|---|---|---|
| **品类毛利**（只算 API 成本） | 轻纪念 ~92% / 标准 ~79% / 完整 ~79% | 单条 API 成本 1.8 / ~12 / ~20 元 |
| ⚠️ **它的正确名字** | **「API 成本占售价的比例」** | **不是毛利率** —— 人工没算进去 |
| **单条人工成本** | **150-300 元/条** | 加微信→收照片→写提示词→生成→抽帧质检→返工；单人 300 元/天、半天到一天 |
| **→ 人工交付下单条净贡献** | **负** | 人工一项就已超过 99 元售价 |
| 现状现金支出 | 60-95 元/月 | 固定 60-90（估算）+ AI ≈4 元 |
| **现金口径打平** | **每月 1-2 条 99 元** | ⚠️ **只覆盖现金支出，把创始人的时间定价为 0** |
| **真实盈亏平衡** | **85 条/月**（≈每天 3-4 条） | （月现金 ~80 + 人力 6,600）÷ 单条净贡献 |
| 会员档 | ❌ **负毛利** | 文档口径月权益成本 47-53 元 > 29.9 元月费；促销 9.9 时**每开一个净亏 37-43 元** |

**核心结论**：
> **「每月 1-2 单就够活」这句话是错的** —— 它把你的时间当成了 0。
> 一个能写出七层架构、跑出 4000+ 条测试的全栈开发者，时薪不可能是 0。
> **真实盈亏平衡是 85 条/月**，这条线以上的量，才是「这是一门生意」。

**这盘生意唯一健康的单元是「一条 99 元的纪念片」，而它健康的前提是人工成本被压掉（标准化/SOP/半自动）或售价抬到 299-599。**

## 六、三条互斥路径 + 舰长裁决

| | 路径 A：纯 C 端 | 路径 B：走殡葬门店 | 路径 C：内容 IP 养泛粉 |
|---|---|---|---|
| 打给谁 | 刚离世的宠主 | 门店手里的窗口期客户 | 泛养宠人群 |
| 第一笔钱 | 最快（2 周） | 1-2 个月 | 最慢（4-8 周） |
| 最大死因 | **时机型需求打不到人**（推荐滞后，平台不会把悲伤内容推给正在悲伤的人） | **绑在无合规资质的灰色行业上**，且失去定价权 | **做成"只有播放没有客资"的账号**，且要求把资源从开发转到内容 |

**三条真的互斥**：要的能力不同（A 要内容打窗口 / B 要 BD / C 要长期养号），单人同时跑三条 = 三条都跑不通。

### 舰长裁决：不选纯 A、不选纯 B —— 走「人工交付的最小闭环」

**02 与 03 在顺序上互相矛盾**（02 说第一件事用门店的真实案例；03 说先纯 C 端再 B）。
审-1 指出：门店入口同时提供 A 最缺的三样东西 —— **真实素材、已建立的信任、正处窗口期的客户**。
**裁决如下**：

1. **案例与信任从门店/社群里来**（解决「时机型需求打不到人」这个死因，也顺手解决「成片质量没验证过」）；
2. **交付走人工，不加小程序**（绕开「0.2.1 没发布」这个障碍，也顺带测「这条链路需不需要真人对接」）；
3. **收费 99 元**，加微信 → 发 5-15 张照片 + 勾 3 条记忆 → 24-48 小时出片；
4. **纯 B（签分成/做 SKU）押后** —— 它把你绑在无合规资质的行业上，风险会传导到你的品牌；
5. **纯 C 不启动** —— 它要求停掉产品迭代，与单人带宽直接冲突。

**这不是「先 A 后 B」，是「A 和 B 的最小交集」：用门店的素材和客户，做 C 端的人工交付。**
