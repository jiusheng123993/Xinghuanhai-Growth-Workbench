## 结构指纹

| 维度 | 填的是 |
|---|---|
| 主体 | 一人公司、创始人本人（台账：单人开发，验证期功能冻结） |
| 阶段 | **产品已成型、市场零验证**：约 8 周开发（台账估算）、R1 五项 P0 改造已完成、测试全绿；注册 17、付费 0、回忆录订单 0 |
| 收入结构 | 预期 = 单品（25.9/18.9、59/45、99/79）+ 会员（88/年）；**实际收入 0**，没有一条跑通的收入线 |
| 稀缺资源 | **注意力与信任**，不是钱。钱有上限压着（验证期预算 ≤3500 元），且已明确不做付费投流 |
| 核心张力 | 继续打磨产品 vs 立刻出门验证；自建流量 vs 借别人的流量（投流自禁、BD 未启动） |
| 锁定机制 | **产品与内容两条线都要一个人扛**，于是「稳定拿到客资」永远排在研发后面，能力建不起来 |
| 压力机制 | 已沉没的开发成本（约 8 周，台账估算；做的还是记忆引擎这种重资产）；小程序只上传了开发版，提交审核与发布仍待本人操作——**做完了却还没真正上线** |
| 想去哪 | 从「没人用、没人付钱」到「至少一个陌生人付过钱」 |

**结构命题**：一个处于**产品已成型、零付费验证**阶段的**单人创始人**，靠**尚未成立的单品+会员收入结构**活着，被**「产品与内容都要他一个人扛」**卡住建不起**稳定获取客资的能力**，还被**已沉没的开发成本 + 做完却没发布的小程序**一直拽着。判定 ✅。

### 这是哪一类问题

三个候选说法都不完全对。

- 「新品类无人验证」**不准确**：赛道有行业级判断支撑——基础殡葬服务已同质化，「情绪服务与纪念品是核心盈利点」是《中国质量报》+中研普华两处独立同向的 🟢 高可信结论。钱在纪念，行业说过了。
- 「工具型产品缺流量」**是表象**：缺流量是结果，不是原因。
- 「有需求但没人收过钱」**最接近，但还得拆一层**：真实需求指向的是**殡葬服务**（64.6% 会办葬礼、一线客单超 2500 元——**两项均 🟡 中可信**，资料包 §B/§C/§G），**不是数字纪念**。没人被问过「你要不要一段 AI 回忆录视频」。

准确说法：**需求真实存在，但需求指向别的供给。你在真实需求旁边另立了一个新需求，而它从未被任何人用钱验证过。**

再加一条常被忽略的属性：**时机型需求**。用户只在「宠物离世/即将离世」那个窗口里需要它，窗口以小时计。所以你**不能等需求自然发生**——只能守在窗口边，或者让别人把窗口里的人递给你。

## 历史同构（含失败与反例）

> 除标注台账/资料包的以外，以下**全部来自我自己的知识，没有联网核验**。不确定的一律标 🔴 并注明「我的记忆可能有误，需舰长核实」。

### 问题家族

| 家族 | 共享结构 | 可能失效的差异 |
|---|---|---|
| F1 需求未验证的新品类 | 品类空白 = 没人用钱投过票 | 别人的「空白」常是试过不划算，不是没人想到 |
| F2 时机型需求 | 需求只在事件窗口出现，供给方造不出需求 | 殡葬、婚庆有线下场所天然截流；数字产品没有物理截流点 |
| F3 工具型产品缺客资 | 产品做完、无人来用，资源全压研发 | 工具类能免费获客再变现，纪念类连自传播都弱 |
| F4 单人带宽下的产品自嗨 | 时间给了做，就没时间给卖 | 有人靠技术资产形成壁垒，前提是壁垒能被买家看见 |
| F5 低客单 + 零复购的情绪单品 | 一次性消费，终身价值低 | 可靠「年度回看/多个宠物」造出弱复购 |
| F6 单一平台依赖 | 全押一个小程序或一个内容平台 | 小程序没有公开分发池，只能靠内容与搜索 |

### 案例

**案例 1（跨行业同构｜🟡）AI 单张内容小程序靠一个爆款玩法爆量**
处境：AI 生成刚够用、单次成本降到几块钱。选择：把能力包成**极简玩法**（传照片→出一套成品），9.9 元级别，小程序承载，靠社交扩散。后来：短期刷屏式爆量，热度快速回落，留存是长期问题。
来源：我的记忆，方向有把握，**具体数字（用户量、留存、持续时间）可能不准，需舰长核实** 🟡。
相同：AI 生成、小程序承载、单次交付、低客单、无存量需求。不同：它**不需要教育**、交付物当场可见；你要先解释，还得等一个悲伤时刻。
机制：**把 AI 能力压成「一句话讲清、几十秒看到结果」的玩法**才有自传播。不能照搬：它卖新奇，你卖悲伤的仪式。类比有效性：中高。

**案例 2（反例/边界｜🟡）网上纪念馆类产品存活很久，但没长成大生意**
处境：扫墓祭奠是真实且长期的需求。选择：做线上纪念馆，靠虚拟祭品、点灯这类小额虚拟商品收费。后来：形态存活很多年，**知名度与体量长期停在小众**。
来源：我的记忆（网上祭扫、云祭扫我确定存在；**具体平台名与经营数据不确定，需舰长核实**）🟡。
相同：情感纪念 + 低频 + 虚拟商品收费 + 人群窄。不同：祭扫有清明这个固定节点，宠物离世没有统一节点。
机制：**「需求真实」与「生意能做大」是两件事**。类比有效性：中。

**案例 3（失败｜高，原子库）囤了 20 万粉、数据漂亮，最后亏 300 万收场**
处境：单粉成本 10 元以下、私域当天盈利 3 倍、高峰日利润 10 万。约束：准入门槛极低、新玩家持续涌入。后来：行业结构恶化、劣币驱逐良币，正规经营者陷入价格劣势——**短期漂亮数据不等于生意成立**。
来源：原子 `XY-KB-257`（本次检索命中，标 high）。教训原文两条：发现恶性竞争苗头立刻调整；**进场前必须预设止损点**。
相同：都在「能力扎实」与「生意成立」之间隔着一段没被验证的距离。不同：它死于同行压价，星河宠记连同行都没有——**没有同行不是优势，是没有参照物**。类比有效性：中。

**案例 4（最贴近的成功案例｜🟡）AI 工具靠「发现空白 + 找对分发者」起量**
处境：细分赛道已有几十款 App，一个高痛点场景是空白。选择：产品做极简（评估+游戏化+监测），**找该人群已有的网红做定位营销**，而不是自己养号。后来：三个月做到十万级用户。
来源：原子 `XY-DY-034`（本次检索命中，标 high）；**案例真实性我未独立核验，需舰长核实**。
相同：空白细分、AI 产品、小团队做出来。不同：它的用户是「正在戒色的年轻人」（需求持续、可被搜索）；你的用户是「此刻正在告别的人」（需求瞬间存在、搜不到）。
机制：**空白赛道能不能成，取决于①痛点是否对准 ②方案是否极简 ③有没有人替你把话说给对的人听**。不能照搬：它有可长期经营的社群对象，你没有。类比有效性：中高。

**案例 5（机制级证据｜高，原子库）空白市场不是坏消息，条件是「痛点即切入点 + 最简方案」**
事实：同一套判断（某品类属「未被完全教育的市场」）在两个不同品类上第二次成立，切入方式是**不做复杂配方，直接给最简方案**。来源：原子 `XY-KS-008`（本次检索命中，标 high）。
机制：**「没人被教育过」不等于「没人要」**，但要求你把方案压到最简。失效边界：当用户必须先被说服「你需要它」时，这套不成立——那不是简化能解决的。

## 赛道推演

> 内置 8 张模板**没有宠物纪念**，走通用推演，归到最近的一张：**形态像模板 C（低客单、可即时成交），教育成本像模板 B（强教育、非共识品）**——价格逻辑照 C、信任逻辑照 B。每条推断都是 🔴 假设。

### 赛道属性

| 检查项 | 判定 | 说明 |
|---|---|---|
| 决策成本 | 家庭级/情绪级 | 金额不大（25.9-99 元），触发时刻极敏感，决策窗口以小时计 |
| 标品/非标 | **非标** | 每只宠物一套成片；对标锚点：闲鱼 AI 复活 5 元/次、博主定制 100-300 元/条（台账） |
| 需不需要教育 | **强需要教育** | 「我可以买一段 AI 纪念视频」这件事本身不在用户认知里 |
| 买用是否同人 | 是 | 宠主自己买、自己看 |
| 信任门槛 | 需要「这个东西可信」 | 用户要交出最私密的照片与情绪，对「做得像不像、体不体面」高度敏感 |

**关键卡点：A→B（教育）+ 时机（能不能正好在窗口出现）。** 判定 🟡——不是内置赛道那种单点卡点。

### 心智阶段 × 内容职能

| 阶段 | 用户状态 | 内容职能 | 建议占比 | 评估指标 |
|---|---|---|---|---|
| A 不觉得需要 | 绝大多数养宠人（离世还早） | 种草/情绪共鸣：陪伴的日常、回忆的价值 | **55-60%** | 播放、收藏、评论里的故事 |
| B 有点兴趣 | 宠物高龄/重病/刚离世 | 专业：这件事可以怎么做、真实成片长什么样 | **25-30%** | 评论区线索率、私信数 |
| C→D 付费 | 已经想买，问怎么买 | 信任：交付过程、真实客户成片、下单路径 | **10-15%** | 下单数、确收 |

1. **会员层每卖一份亏钱**（台账：促销期每开一个会员净亏 37-43 元，正价期也亏）。不只是成本问题——它意味着「卖会员」现在做得越多越危险。
2. **引流品和核心品是两群人**。免费打卡吸引「日常记录党」，付 99 元的是「离别纪念刚需」——**引来的和付钱的是两组不同的人，不能指望前者往前走一步就变成后者**（本文判断，依据台账的产品分层：引流品＝打卡/时光线，核心品＝回忆录）。日常记录党不会因为打了半年卡，就在宠物离世时想起你——**除非内容层一直给这个场景做铺垫**。

### 获客路径与成交场景

- 路径类型：建议走**订单粉**，不走「强人设 + 私信主动咨询」。`XY-DY-073` 支持的是后半句：它讲的「精准粉」是**已在直播间消费过 100-200 元的人**，导私域后复购成交率 30%+、客单 1500-3000 元——订单粉的价值在于**需求先被真金白银证明过一次**。前半句「离世的私密性让用户不愿开口私信、只愿默默付一次小钱拿成品」**是本文推断，没有原子与台账支撑，标 🔴**。
- 成交场景：25.9-99 元端内直接成交；300 元以上的后端（实物纪念品、加急、多宠套系）必须在私域 1v1 完成。
- 必须承认的冲突：`XY-KB-395` 的门槛是客户年产值 > 100 元，现有客单 25.9-99 元**不达标**。要么把客单抬过 100，要么别指望私域承接。
- 私域第一句：不能是「您好」，也不能上来甩报价（`xy-close` 信条 2）。

## 成交链现状

**结论：根本还没走到成交那一环——前端信任尚未铺开。**（`xy-close` Phase 4 的两种结论之一）

Phase 4 的三条鉴别，逐条查台账：成交率最高的是哪类场景（无记录）、客户进来是「已经想买」还是「来比价」（无记录）、转介绍来的客户成交是否更顺（无记录，只有 7 天会员的推荐裂变设计，无使用数据）。三条**全部无数据**，只有一种可能：**这条链还没开始跑**。现在优化话术、逼单、报价锚点，都是在优化一个还没接通的东西。

### 0 付费的事实含义

**产品尚未被市场验证。** 不是失败，也不能粉饰成「潜力巨大」。可核对的事实：

1. **分母太小，任何转化率都没意义**：17 个注册，台账未记载其中有多少是真人（含创始人自己/测试账号的可能），标 🔴 待核。
2. **可能连新版功能都没真正上线**：0.2.0、0.2.1 只是**上传了开发版**，「提交审核→发布」仍待本人操作（台账原文），线上跑的很可能还是上一版——**用户遇到的可能是旧界面旧流程**。
3. **前端连「被看见」都还没有**：无已发布内容、无获客渠道记录。
4. **唯一真实的留存孤证**：用户「不忘/可乐」有 43 条真实对话（台账）。这证明「有人真的在用健康/对话功能」，但**不能证明纪念功能的付费意愿**，且这批数据后来在生产事故里丢了 32 条。
5. **会员线即使开单也是负毛利**，重构完成前，「第一笔钱」若来自会员反而放大亏损。

立项书自定判据是「首单付费转化 ≥1%」，按现有 17 个注册**统计上没有意义**——要么先把分母做到三位数，要么把样本换成「精准到窗口人群」的小样本（`XY-KB-330` 的做法：**找 50 个真实的人，让他们花钱买，再收集反馈**）。

## 三种可选打法（互斥）

统一前提：单人产能、不做付费投流、验证期功能冻结。只能认真跑一条。

### 路径 A：做 C 端产品（直接面向离世宠主收费）

| 项 | 内容 |
|---|---|
| 打给谁 | 宠物刚离世/确诊重病/高龄的宠主（台账 B 层「离别纪念刚需」） |
| 怎么获客 | 小红书「告别/回忆」内容，靠真实成片对比 + 告别故事；承接走**订单粉**（端内先花 25.9 元出一次轻纪念，再进私域谈 99-299） |
| 什么时候收到第一笔钱 | **最快，2 周内**。发 4-6 条内容 + 进 3 个宠物社群（立项书的种子方案）就能测 |
| 最大死因 | **时机型需求打不到人**：需求只在那个窗口出现，内容推荐是滞后的，平台也不会把悲伤内容推给正在悲伤的人。次生：离世主题被限流 |
| 必须先改 | ①**先把 0.2.1 提交审核并发布**——台账写明 0.2.0/0.2.1 只是**上传了开发版**、线上仍是上一版；**版本没发布前，A 在端内测出的任何数据都不可解释**；②把「日常记录党」和「离别宠主」在内容层分开打 |
| 依赖假设 | 🔴 1、2、3、5、7 |

### 路径 B：做 B 端供给（数字纪念做成殡葬店/宠物医院的增值 SKU）

| 项 | 内容 |
|---|---|
| 打给谁 | 一线城市宠物殡葬门店、宠物医院、宠物临终关怀机构（台账：是否对接过=未记载，等于未启动） |
| 怎么获客 | 不靠公域内容，靠直接 BD。给店主的不是方案，是**能当场演示的东西**：扫码→上传照片→当天出片。结算按单分成或按次服务费（同构 `XY-KB-235`：你只占获客与成交环节，场景与交付由合作方承担） |
| 什么时候收到第一笔钱 | **1-2 个月**，谈成一家就能出货，周期取决于 BD 效率而不是产品 |
| 最大死因 | **合作方本身没有合规资质**（资料包：北京无一家真正合规的殡葬店）。你把自己绑在灰色行业上，风险会传导；门店掌握客户关系，你很快从「产品方」变成「供应商」，失去定价权 |
| 必须先改 | 对外承诺收窄成「提供数字纪念内容生成」，不承诺导流、不承诺效果；结算先定清楚是佣金还是服务费 |
| 依赖假设 | 🔴 1、10 |

### 路径 C：做内容 IP 带工具（先养泛粉，再转化）

| 项 | 内容 |
|---|---|
| 打给谁 | 泛养宠人群（台账 A 层「日常记录党」），用陪伴日常内容养粉 |
| 怎么获客 | 小红书/视频号做「养宠日常 + 时光线回忆」，把记录做成习惯，把纪念功能当情绪高潮点推 |
| 什么时候收到第一笔钱 | **最慢，4-8 周**，且需要持续产能 |
| 最大死因 | **做成「只有播放没有客资」的账号**（`XY-MA-1300`，**全库命中**：蹭热点、情景剧，点赞 99+、私信咨询 0）。日常记录类粉丝对 99 元回忆录的付费意愿天然低于正在经历离别的人；而且这条路要求把资源从开发转到内容，与「单人带宽 + 验证期功能冻结」**直接冲突** |
| 必须先改 | 若走这条，必须承认「产品迭代要停」——一个人不可能同时日更内容又把产品做好 |
| 依赖假设 | 🔴 4、5、6 |

**三条为什么真的互斥**：要的能力不同（A 要内容打窗口，B 要 BD，C 要长期养号），第一笔钱时间差 **2-4 倍**（2 周 / 1-2 月 / 4-8 周；最快 2 周、最慢 4-8 周，8÷2 = 4 倍），钱卡在不同环节（A 卡触达窗口，B 卡签下合规门店，C 卡把泛粉变精准）。单人同时跑三条 = 三条都跑不通。

**建议顺序：人工闭环先行 → 门店只当素材与窗口 → C 最后**（本文据此**撤回原稿的「纯 C 端 A → B」**）

⚠️ **先交代一处与报告 02 的冲突**：02 的收口是「用 3 家宠物医院/殡葬门店手上的真实案例做出 5 条成片」，那是**路径 B 的入口**；而本文原稿把 B 排在 A 之后、写成「1-2 个月才收到第一笔钱」。**两处不能各说一套。** 本文按「**门店只当素材与信任来源，不走分成**」这一口径统一：

1. **第一步（2 周内，人工交付的最小闭环）**：把「完整回忆录 99 元」摆到 3-5 个真实离世宠主面前收款——成本最低、结果最快，直接回答「这个需求到底有没有人付钱」；**案例优先取自门店与社群里正经历离别的人**，同一件事顺手把 A 最缺的真实素材补上。

2. **第二步（不是另起一条路，而是同一条线的延伸）**：门店只当**窗口与素材来源**。它的价值是天然守在窗口边上（手里正握着刚失去宠物的客户）；先用它换案例与信任，**不在这时候谈按单分成**——既不把品牌绑在没有合规资质的灰色行业上，也不至于从产品方降成供应商、丢掉定价权。

3. **第三步**：C 需要长期产能，验证完成前不启动；人工闭环拿到正向反馈之后，再谈把交付产品化、以及要不要真做 B 端分成。
